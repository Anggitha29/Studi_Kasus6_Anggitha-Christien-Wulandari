### Penjelasan Kode Program

Penjelasan Kode Program

1. **Import JSON**
   Digunakan untuk mengolah dan menyimpan data dalam format JSON.

2. **Membaca Data JSON**
   Digunakan untuk membuka dan membaca data inventaris yang sudah tersimpan di file Data.json agar dapat digunakan oleh         program.

3. **While Loop**
   Digunakan agar program dapat berjalan terus dan menampilkan menu secara berulang sampai pengguna memilih untuk keluar.

4. **Menu Program**
   Digunakan untuk memberikan pilihan kepada pengguna, yaitu menampilkan data barang, menambahkan data barang, dan keluar       dari program.

5. **Percabangan**
   Digunakan untuk menentukan proses yang akan dijalankan sesuai dengan pilihan menu dan kategori barang yang dipilih           pengguna.

6. **Penjelasan Kode Program**
   Digunakan untuk menampilkan seluruh data barang yang tersimpan dalam file JSON.

7. **Input Data Barang**
   Digunakan untuk menerima informasi barang baru berupa nama, harga, stok, dan satuan.

8. **Kategori dan Kode Barang**
   Digunakan untuk menentukan kategori barang serta membuat kode barang secara otomatis berdasarkan kategori yang dipilih.

9. **Dictionary**
   Digunakan untuk menyimpan informasi setiap barang dalam bentuk pasangan data, seperti kode barang, nama, kategori, harga,    stok, dan satuan.

10. **Append**
    Digunakan untuk menambahkan data barang baru ke dalam kumpulan data yang sudah ada.

11. **Menyimpan Data ke JSON**
    Digunakan untuk menyimpan seluruh data terbaru ke dalam file Data.json sehingga data yang telah ditambahkan tetap            tersimpan meskipun program ditutup dan dijalankan kembali.

12. **Break**
    Digunakan untuk menghentikan perulangan program ketika pengguna memilih menu keluar.
